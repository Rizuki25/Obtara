## Skala

- Skor: `2` mandiri, `1` dengan bantuan, `0` gagal/berhenti.
- Kemudahan: `1` sangat sulit hingga `5` sangat mudah.
- Bantuan: `0` tidak ada, `1` probing netral, `2` petunjuk arah, `3` moderator menunjukkan kontrol.
