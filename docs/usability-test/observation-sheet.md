## Skala

- Skor: `2` mandiri, `1` dengan bantuan, `0` gagal/berhenti.
- Kemudahan: `1` sangat sulit hingga `5` sangat mudah.
- Bantuan: `0` tidak ada, `1` probing netral, `2` petunjuk arah, `3` moderator menunjukkan kontrol.
- Skor `2` hanya jika tugas selesai sebelum bantuan; pertanyaan tindak lanjut setelah sukses tidak dihitung sebagai bantuan.
- Skor `1` bila bantuan tingkat 1–2 membantu penyelesaian.
- Skor `0` bila perlu bantuan tingkat 3, salah status, berhenti, atau safety stop.
